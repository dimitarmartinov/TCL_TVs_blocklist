# TCL_TVs_blocklist
A blocklist for AdGuard Home specifically designed for TCL TVs

This is Initial testing. More domains will be added as additional DNS query logs are collected from the TV.
It is currently being tested on a TCL C8L model and its purpose is to block as many ads, telemetry, and tracking domains as possible while keeping Google Assistant and system updates functional.
As always, use with caution and please report any issues you encounter!
